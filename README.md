# Ahmad Aziz — Modern Web Portfolio

> **Associate AI Engineer • Computer Science Junior @ UET Peshawar • Co-Founder CNCF Peshawar**

An ultra-modern, high-craft web portfolio showcasing applied machine learning systems, autonomous multi-agent pipelines, distributed web platforms, and community leadership.

---

## ⚡ Key Highlights & Systems

- **FloodCommand (AtomCamp National AI Hackathon)**: 5-Agent autonomous disaster response pipeline parsing multilingual Urdu/Pashto WhatsApp SOS messages and dispatching rescue boats in under 90 seconds.
- **MediGuide**: Bilingual (Urdu/English) clinical symptom-triage chatbot with real-time red-flag escalation warnings.
- **AudiWave**: Manifest V3 Chrome Extension converting browser audio streams to American Sign Language (ASL) gloss tokens.
- **CNCF Peshawar Ecosystem**: Cloud-native microservices architecture, container orchestration, and community tech initiatives.
- **Live Multi-Agent Telemetry Stream**: Interactive state machine execution and tokenization console.

---

## 🛠️ Tech Stack & Architecture

- **Core**: Vanilla HTML5, Modern Vanilla CSS3, ES6+ JavaScript
- **Design System**: Studio Dark Tech, Glassmorphism, Bento Grid Architecture
- **Typography**: Plus Jakarta Sans, Outfit, Instrument Serif, Space Grotesk
- **Assets**: Optimized High-Resolution 3D Telemetry Graphics
